# نظام التصميم — سرمد

## 1. الاتجاه الفني

**هادئ، عربي، أنيق، شخصي، قليل العناصر.**

سرمد صفحة إهداء رقمية؛ بطاقة الإهداء هي مركز التجربة، والهدف أن يخصصها المستخدم باسم ثم يشارك رابطًا سهل الفتح والتعديل.

## 2. الألوان الأولية

| الدور | اللون |
|---|---|
| الأخضر الأساسي | `#285B42` |
| خلفية الصفحة | `#F5F4EC` |
| سطح البطاقة الثانوي | `#E8EDE3` |
| نص ثانوي | `#647563` |
| حدود هادئة | `#D7DED3` |
| أبيض | `#FFFFFF` |

## 3. الخطوط

- خط الواجهة: IBM Plex Sans Arabic.
- خط العناوين والبطاقة: Amiri عند الحاجة.
- خط الآيات: Amiri Quran حاليًا، مع ضرورة مراجعة علامات الضبط على الأجهزة المختلفة.

## 4. بنية الصفحة

1. رأس صغير يحتوي رمز سرمد واسم العلامة.
2. عنوان يتغير عند فتح رابط مخصص باسم.
3. بطاقة الإهداء في مركز الاهتمام.
4. رابط المشاركة يظهر أسفل البطاقة عند طلبه.
5. محتوى القراءة والدعاء.
6. تذييل بسيط.

## 5. بطاقة الإهداء

- موضع الاسم قابل للتحرير مباشرة داخل البطاقة.
- عند فتح رابط مخصص يظهر الاسم تلقائيًا.
- يظهر إجراء «تغيير الاسم» بوضوح عند وجود اسم.
- تغيير الاسم يحدّث معامل الرابط `to` دون إعادة تحميل الصفحة.
- يجب ألا يتكرر اسم المُهدى إليه في أكثر من موضع داخل بطاقة الإهداء.

## 6. المشاركة

- إجراء رئيسي واحد: «مشاركة الإهداء».
- يستخدم Web Share API عند توفرها.
- عند عدم توفر المشاركة الأصلية، يُنسخ الرابط ويظهر في حقل واضح.
- حقل الرابط للقراءة فقط مع زر «نسخ الرابط».
- الرابط يعكس الاسم الحالي دائمًا.
- مشاركة الصورة وPDF والطباعة مؤجلة في الواجهة حتى استقرار تجربة الرابط.

## 7. الأبعاد والاستجابة

- Mobile-first.
- RTL صحيح في كل الأحجام.
- مساحة لمس الأزرار مناسبة.
- حقل الرابط يدعم الاتجاه LTR لسهولة قراءته ونسخه.
- لا تستخدم قوائم من خيارات غير نشطة.

## 8. الوصولية

- دعم لوحة المفاتيح.
- تسميات واضحة لحقل الاسم والرابط.
- مؤشر تركيز مرئي.
- رسائل نجاح وفشل عبر `aria-live`.
- احترام إعداد تقليل الحركة.


## 9. استراتيجية Mobile-first

- القاعدة الأساسية مصممة أولًا لشاشات الهواتف الصغيرة بعرض يبدأ من 320px.
- الحاوية والبطاقة بعرض المساحة المتاحة، مع هوامش آمنة ثابتة على الجانبين.
- نقاط التحسين التدريجي: 380px للهواتف الضيقة، 600px للهواتف الكبيرة والأجهزة المتوسطة، 768px للتابلت، و1024px للشاشات الواسعة.
- استخدام `100svh` مع بديل `100vh` لتقليل قفزات الارتفاع مع شريط المتصفح في Android.
- احترام مناطق الأمان عبر `env(safe-area-inset-*)`، ومنع التمرير الأفقي غير المقصود.
- حقل الاسم سطر واحد مع مساحة رأسية كبيرة للتشكيل، ويُمنع إدخال سطر جديد.
- لا يقل ارتفاع أزرار التفاعل الأساسية عن 44px لتسهيل اللمس.
- نصوص القرآن والدعاء تستخدم أحجامًا مرنة ومسافات أسطر مريحة على الشاشات الضيقة.
- في الوضع الأفقي القصير، تُقلل المسافات وتظل الصفحة قابلة للتمرير رأسيًا.
