## ملاحظات تنفيذية

- تم إنشاء التطبيق دون إضافة lockfile؛ بعد أول `npm install` محلي، يجب رفع `package-lock.json` واستخدام `npm ci` في CI.
- لا تنفذ مراحل التصدير قبل استقرار شكل البطاقة والخطوط.
- لا تضع أزرار الأدوات داخل العنصر الذي سيتم تصديره.
- معاينة المشاركة الاجتماعية بالاسم ليست ضمن MVP؛ HTML على GitHub Pages ثابت ولا يمكنه توليد OG metadata مختلفة لكل query parameter دون خدمة وسيطة أو توليد صفحات مسبقًا.
- لا تضف أي نص ديني أو ادعاء شرعي قبل مراجعة النص ومصدره.
