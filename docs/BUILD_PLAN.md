## الاختيارات التقنية

- React + TypeScript + Vite.
- Tailwind CSS.
- Lucide React.

- jsPDF للـ PDF.

لا نضيف React Router أو Backend أو قاعدة بيانات في الإصدار الأول.

## ملاحظات تنفيذية

- ابدأ بأحدث إصدارات مستقرة ومتوافقة وقت إنشاء المشروع، وثبّت الإصدارات في lockfile.
- لا تنفذ مراحل التصدير قبل استقرار شكل البطاقة؛ لأن جودة المخرجات تعتمد على جودة عنصر البطاقة والخطوط.
- لا تضع أزرار الأدوات داخل العنصر الذي سيتم تصديره.
- معاينة المشاركة الاجتماعية بالاسم ليست ضمن MVP؛ HTML على GitHub Pages ثابت ولا يمكنه توليد OG metadata مختلفة لكل query parameter دون خدمة وسيطة أو توليد صفحات مسبقًا.
- لا تضف أي نص ديني أو ادعاء شرعي قبل مراجعة النص ومصدره.
