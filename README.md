# سرمد | Sarmad

**صفحة إهداء رقمية باسمك أو باسم من تحب.**

سرمد مشروع مستقل ضمن منظومة ناوي. وظيفته إنشاء صفحة إهداء شخصية قابلة للمشاركة كرابط أو التصدير كصورة أو PDF أو طباعتها.

> سرمد ليس تطبيق أذكار أو أوراد. محتوى الأذكار والقراءة سيكون ضمن تطبيق مستقل.

## الإصدار الحالي

تم إنشاء أساس التطبيق باستخدام React + TypeScript + Vite وTailwind CSS.

- بطاقة إهداء عربية RTL بتصميم Responsive.
- الاسم يُكتب مباشرة في موضعه داخل البطاقة.
- الصفحة العامة تعرض دعوة لكتابة الاسم داخل البطاقة نفسها.
- عند وجود `?to=` في الرابط يظهر الاسم تلقائيًا.
- كتابة الاسم تحدّث معامل الرابط باستخدام `URLSearchParams` وHistory API.
- لا يوجد Backend أو تسجيل دخول أو قاعدة بيانات.

## التقنية

- React 19 + TypeScript 7
- Vite 8
- Tailwind CSS 4
- Lucide React
- GitHub Actions + GitHub Pages

التصدير إلى PNG وPDF والمشاركة المباشرة والطباعة مخطط لها في المراحل التالية، ولم تُنفّذ بعد.

## التشغيل محليًا

يتطلب Node.js 22.12 أو أحدث.

```bash
npm install
npm run dev
```

للتحقق من الأنواع وبناء نسخة الإنتاج:

```bash
npm run typecheck
npm run build
npm run preview
```

ينشئ `npm install` ملف `package-lock.json` محليًا؛ يجب الاحتفاظ به في المستودع بعد أول تثبيت مستقر.

## النشر

يوجد سير عمل GitHub Actions في `.github/workflows/deploy.yml` ينشر مجلد `dist` إلى GitHub Pages عند الدفع إلى `main`.

من إعدادات المستودع، اختر **Settings → Pages → Build and deployment → Source: GitHub Actions**.

تم ضبط Vite على مسارات أصول نسبية `./` لتعمل نسخة المشروع على GitHub Pages وكذلك على نطاق مخصص مستقبلًا.

## رابط الإهداء

يُحفظ الاسم داخل معامل URL، مثل:

`?to=فاطمة`

يستخدم التطبيق `URLSearchParams` للقراءة والكتابة والترميز.

## مبادئ المشروع

1. صفحة واحدة وتجربة مباشرة.
2. الاسم جزء من التصميم، وليس نموذجًا منفصلًا.
3. الصفحة العامة والصفحة المخصصة تستخدمان نفس المكونات.
4. ما يظهر في التصدير يجب أن يطابق بطاقة الإهداء على الشاشة.
5. لا نضيف Backend أو حسابات ما دام المنتج لا يحتاجها.
6. لا ننسب نصًا دينيًا أو وعدًا بالأجر دون مراجعة ومصدر واضح.
