# سرمد | Sarmad

**صفحة إهداء رقمية باسمك أو باسم من تحب.**

[**معاينة سرمد مباشرة**](https://sarmad.nawy.app/)

سرمد صفحة مستقلة لإنشاء إهداء شخصي، وتخصيصه باسم، ثم مشاركته كرابط يفتح بالاسم نفسه.

## التجربة الحالية

- بطاقة إهداء عربية RTL بتصميم متجاوب.
- الاسم يُكتب مباشرة داخل البطاقة.
- عند فتح رابط يحتوي على `?to=` يظهر الاسم تلقائيًا.
- يمكن تغيير الاسم من البطاقة؛ ويتحدث الرابط تلقائيًا دون إعادة تحميل الصفحة.
- زر «مشاركة الإهداء» يفتح المشاركة الأصلية في الهاتف أو المتصفح عندما تكون متاحة.
- عند عدم دعم المشاركة، يُنسخ الرابط تلقائيًا ويظهر في حقل واضح يمكن نسخه مرة أخرى.
- لا يوجد Backend أو تسجيل دخول أو قاعدة بيانات.

**مشاركة الرابط هي طريقة المشاركة النشطة حاليًا.** تصدير الصورة وPDF والطباعة مؤجلة لحين استكمال تجربة الرابط.

## التثبيت والعمل دون اتصال

سرمد قابل للتثبيت كتطبيق ويب تقدمي (PWA)، دون حساب أو Backend.

- على Android: استخدم خيار «تثبيت التطبيق» أو «إضافة إلى الشاشة الرئيسية» من المتصفح.
- على iPhone وiPad: افتح قائمة المشاركة ثم «إضافة إلى الشاشة الرئيسية».
- بعد أول زيارة عبر الإنترنت واكتمال تخزين ملفات التطبيق، يمكن فتح الصفحة ومحتواها دون اتصال.
- روابط الأسماء التي تحتوي على `?to=` تظل قابلة للفتح دون اتصال بعد تخزين التطبيق على الجهاز.
- الملفات الأساسية تُحدَّث تلقائيًا عند توفر إصدار جديد. خطوط Google تُخزَّن بعد تحميلها، مع استخدام خطوط النظام كبديل عند عدم توفرها.
- التثبيت اختياري؛ يظل الرابط العادي هو وسيلة المشاركة الأساسية.

## التقنية

- React 19 + TypeScript 7
- Vite 8
- Tailwind CSS 4
- Lucide React
- GitHub Actions + GitHub Pages

## التشغيل محليًا

يتطلب Node.js 22.12 أو أحدث.

```bash
npm install
npm run dev
```

للتحقق من الأنواع وبناء نسخة الإنتاج:

```bash
npm run typecheck
npm run build
npm run preview
```

ينشئ `npm install` ملف `package-lock.json` محليًا؛ يجب الاحتفاظ به في المستودع بعد أول تثبيت مستقر.

## النشر

يوجد سير عمل GitHub Actions في `.github/workflows/deploy.yml` ينشر مجلد `dist` إلى GitHub Pages عند الدفع إلى `main`.

من إعدادات المستودع، اختر **Settings → Pages → Build and deployment → Source: GitHub Actions**.

تم ضبط Vite على مسارات أصول نسبية `./` لتعمل نسخة المشروع على نطاق المعاينة المخصص وGitHub Pages.

## رابط الإهداء

يُحفظ الاسم داخل معامل URL، مثل:

`?to=فاطمة`

يستخدم التطبيق `URLSearchParams` للقراءة والكتابة والترميز. لا يُحفظ الاسم على خادم؛ الرابط نفسه يحمل الاسم ويعرضه عند فتح الصفحة.

## ملاحظة عن معاينة الرابط

بيانات معاينة المشاركة الاجتماعية (Open Graph) ثابتة لأن الموقع منشور كصفحة GitHub Pages دون Backend. عنوان ووصف المشاركة عبر نافذة المشاركة الأصلية يتضمنان اسم المُهدى إليه، لكن معاينة بعض التطبيقات قد تعرض الوصف العام للموقع.

## مبادئ المشروع

1. صفحة واحدة وتجربة مباشرة.
2. الاسم جزء من التصميم، وليس نموذجًا منفصلًا.
3. الرابط يحمل الاسم، ويظل قابلًا للتعديل.
4. لا نضيف Backend أو حسابات ما دام المنتج لا يحتاجها.
5. لا ننسب نصًا دينيًا أو وعدًا بالأجر دون مراجعة ومصدر واضح.
