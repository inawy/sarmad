# سرمد | Sarmad

**صفحة إهداء رقمية باسمك أو باسم من تحب.**

سرمد مشروع مستقل ضمن منظومة ناوي. وظيفته إنشاء صفحة إهداء شخصية قابلة للمشاركة كرابط أو التصدير كصورة أو PDF أو طباعتها.

> سرمد ليس تطبيق أذكار أو أوراد. محتوى الأذكار والقراءة سيكون ضمن تطبيق مستقل.

## فكرة الإصدار الأول

- صفحة واحدة بتصميم موحد وهوية سرمد.
- الصفحة العامة تعرض دعوة لطيفة لكتابة اسم صاحب الإهداء داخل موضع الاسم نفسه.
- عند فتح رابط مخصص، يظهر الاسم مباشرة في الهيدر.
- يمكن تعديل الاسم وإنشاء رابط إهداء جديد.
- مشاركة الرابط، وتصدير البطاقة PNG أو PDF، والطباعة.
- لا حسابات، ولا Backend، ولا قاعدة بيانات في الإصدار الأول.

## التقنية

- React + TypeScript
- Vite
- Tailwind CSS
- Lucide React
- html-to-image لتصدير PNG
- jsPDF لإنشاء PDF
- Web Share API للمشاركة عند دعم المتصفح
- GitHub Actions + GitHub Pages للنشر

## رابط الإهداء

يُحفظ الاسم داخل معامل URL، مثل:

`?to=فاطمة`

يجب استخدام `URLSearchParams` للقراءة والكتابة والترميز، وعدم تركيب الرابط يدويًا.

## مبادئ المشروع

1. صفحة واحدة وتجربة مباشرة.
2. الاسم جزء من التصميم، وليس نموذجًا منفصلًا.
3. الصفحة العامة والصفحة المخصصة تستخدمان نفس المكونات.
4. ما يظهر في التصدير يطابق بطاقة الإهداء على الشاشة.
5. لا نضيف Backend أو حسابات ما دام المنتج لا يحتاجها.
6. لا ننسب نصًا دينيًا أو وعدًا بالأجر دون مراجعة ومصدر واضح.

## حالة المشروع

مرحلة التأسيس والتصميم. لم يبدأ تنفيذ واجهة الإنتاج بعد.
